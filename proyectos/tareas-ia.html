Tareas redactadas con IAAI-drafted tasks

Herramienta interna que crea tareas en Bitrix24 a partir de un pedido corto, con título y descripción redactados por un LLM.

Internal tool that creates Bitrix24 tasks from a short request, with title and description drafted by an LLM.

ContextoContext

Cargar tareas bien redactadas llevaba tiempo y quedaban descripciones incompletas.

Writing well-structured tasks took time and descriptions were often incomplete.

Qué construíWhat I built

  • Formulario local donde se escribe el pedido en pocas palabras.
  • Llamada a la API de Anthropic con salida estructurada validada por JSON Schema.
  • Creación de la tarea en Bitrix24 por su API REST.
  • Local form where the request is written in a few words.
  • Anthropic API call with structured output validated by JSON Schema.
  • Task creation in Bitrix24 through its REST API.

Decisiones técnicasTechnical decisions

  • Salida validada por esquema: si el modelo no cumple el formato, la tarea no se crea.
  • La persona revisa y aprueba antes de publicar.
  • Schema-validated output: if the model doesn’t match the format, no task is created.
  • A person reviews and approves before publishing.

ResultadoOutcome

  • Tareas consistentes en segundos, con el formato que usa el equipo.
  • Consistent tasks in seconds, in the format the team uses.
