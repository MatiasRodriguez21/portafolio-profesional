Inmobiliaria (proyecto personal)Real estate site (personal project)

Sitio de propiedades en venta y alquiler con filtros, favoritos y ficha con mapa.

Property listings for sale and rent with filters, favorites and a detail page with a map.

ContextoContext

Un sitio inmobiliario de ejemplo, pensado para mostrar cómo organizo una aplicación de React.

A sample real estate site, built to show how I structure a React application.

Qué construíWhat I built

  • Filtros por ubicación, tipo, precio y orden guardados en la URL, para compartir búsquedas y usar el botón Atrás.
  • Hooks propios para carga de datos y favoritos, y una capa de servicio que simula una API.
  • Estados de carga, vacío, error y página 404; SEO por página con las etiquetas nativas de React 19.
  • Filters by location, type, price and sort stored in the URL, so searches can be shared and the Back button works.
  • Custom hooks for data loading and favorites, plus a service layer that mocks an API.
  • Loading, empty, error and 404 states; per-page SEO with React 19 native tags.

Decisiones técnicasTechnical decisions

  • Lógica de filtrado y orden como funciones puras, cubiertas con tests de Jest.
  • Una sola fuente de verdad para los filtros (la URL) en lugar de estado duplicado.
  • Filtering and sorting logic as pure functions, covered by Jest tests.
  • A single source of truth for filters (the URL) instead of duplicated state.

ResultadoOutcome

  • Demo pública y código abierto.
  • Public demo and open source code.
